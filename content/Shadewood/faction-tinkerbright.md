## Team Rule: Teleportation Tech

Each Gnome gets a special action called "Set Teleportation Pad".

### Special Action: Set Teleportation Pad

Once per battle, each Gnome can place down a teleportation pad token. 

Whenever any unit moves onto the teleportation pad token, automatically move that unit 3 hexes in the exact direction it was moving when moving onto the teleportation token. This move can go through all terrain, but must clear terrain with the 3 hex range. If it doesn't, teleport the max number of hexes in which it lands on a hex it can be placed. Finish any movement left over from the movement action.

Whenever a Gnome jumps into a teleporter, all weapons get +1 to all power stats (to a maximum of +1). 

Whenever any non-Gnome unit uses a teleporter, they take d3 + 1 damage.
